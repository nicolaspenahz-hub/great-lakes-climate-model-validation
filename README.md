# Validating Regional Climate Models against CaSR for the Great Lakes Region

This repository contains the code, figures, and paper for a climate model validation project focused on the Great Lakes region.

## Project Overview

This project evaluates how well regional and global climate models represent historical climate patterns over the Great Lakes region during 1980–2005. The Canadian Surface Reanalysis (CaSR) is used as the reference dataset and compared with:

- North American CORDEX regional climate model simulations
- ERA-Interim-driven CORDEX simulations
- CMIP5 global climate model simulations

The analysis focuses on:

- Annual mean surface air temperature
- Annual mean precipitation
- Bias components, including total bias, structural bias, lateral and lower boundary condition effects, and CMIP5 bias
- Lake–land diurnal temperature range (DTR)

## Research Question

The main objective of this project is to determine whether regional downscaling improves the representation of Great Lakes climate patterns compared with coarser global climate models.
